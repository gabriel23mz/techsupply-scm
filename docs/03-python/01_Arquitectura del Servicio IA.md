# Arquitectura del Servicio IA

El servicio Python implementa un microservicio FastAPI desacoplado encargado de la optimización logística. Se comunica exclusivamente mediante contratos JSON con el backend Node.js.

Responsabilidades:
- Optimizar jornadas.
- Ejecutar metaheurísticas.
- Calcular recorridos.
- Integrarse con OSRM.
